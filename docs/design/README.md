# Visual references

## Approved light-direction concept

- File: `virgostars-desktop-light-reference.webp` (compressed, repository-friendly preview).
- Status: **approved visual direction** by the maintainer, **not** a finished UI and not an astronomical computation fixture.
- Product naming in the visual has been aligned to **VirgoStars Desktop**.
- Intended use: visual review of navigation hierarchy, central chart size, pale workspace, purple sidebar and contextual panels. Not intended as a shipped runtime asset.
- Provenance: concept image selected in the project's design conversation on 2026-11-10; optimized and title-adjusted for repository documentation.
- Visibility: keep in the private design repository for now. The preview contains example personal details and must be replaced with **entirely synthetic/approved subject data** before publishing this repo or reusing in public app-store screenshots, docs or promotional materials.
- This preview is a small thumbnail for pull-request/documentation review; the maintainer's source concept should be retained privately and a production-quality mockup prepared during implementation.
- All values, positions, labels and charts shown are illustrative. Validate real outputs using the astronomy and astrology libraries; do not scrape/mock data from the design image.

Design constraints and proposed color tokens are in [UI Design Guidelines](../UI_DESIGN_GUIDELINES.md).

The dark-mode reference has **not yet been formally approved**. When designed, it must preserve layout and interaction conventions from the accepted light reference.
