# Regolo directions in Desktop

Status: **prototype, local integration**. The Functions panel offers simplified primary, symbolic and secondary progression for an active chart with a known time. The reference date is interpreted in UTC with the radix UTC time of day. Fractional years use Moment's calendar-year difference, following the original Regolo method. A simplified primary year corresponds to four minutes after the radix instant; a secondary progression year corresponds to one day. Symbolic directions shift each natal body one degree per year and reverse the direction for bodies with negative natal longitude speed.

The native provider calculates timed charts, with its own range and availability errors; no approximate ephemeris is substituted. The renderer receives the resulting chart facts. The progression is displayed as a second chart, while primary and symbolic modes use the direction layer. The settings restrict the house system to one available in both charts. Ordinary natal aspects are still shown; dedicated directed-aspect calculation is not claimed. A local WebView2 smoke test opened and drew simplified primary directions using the live-sky chart. This does not establish visual or numerical parity against Regolo. The local setup requires the Functions and Charts development worktrees, linked as described in [Advanced features handoff](ADVANCED_FEATURES_HANDOFF.md). These changes are not released.
