# Advanced chart features — integration checkpoint

Status: **prototype work in progress**, 2026-11-18. No release or visual acceptance is implied.

- Synastry has a compact local-archive picker, swap and an optional outer ring of current transits. The transit chart is calculated for the radix location and labelled with its instant. It is independent of the partner and the aspect table remains radix → partner. The ring has not yet been visually accepted in WebView2.
- Deflective synastry and deflection to a house have a prototype implementation in the isolated Charts worktree and a gated Desktop control. Desktop enables it only when the renderer exports `SYNASTRY_DEFLECTION_VERSION = 1` and Vehlow houses are selected. The local development dependency is linked to that worktree. Ordinary cross-aspect rows are hidden while deflection is active. The renderer was built and its geometry tested, but visual comparison and release remain pending.
- Regolo's `@ui/src/app/pagine/strumenti/direzioni.component.ts` (commit `87636d88f22b85470ae3cb7a52d5280b9f43e018`) defines symbolic directions as one degree per fractional calendar year, secondary progressions as one day per fractional calendar year, and simplified primary directions as four minutes per fractional calendar year. Its date arithmetic uses Moment's fractional year difference. The isolated Functions and Charts worktrees and Desktop now include a prototype integration: see [directions](DIRECTIONS.md). Do not substitute conventional primary directions.
- The web solar-return location picker uses an online Leaflet/OpenStreetMap map, reverse geocoding and timezone lookup. Desktop now offers a coordinate picker on an owner-approved offline map in private-artwork builds, with 1×–4× zoom and a debounced native ASC/MC/cusp preview for the chosen return. A local WebView2 test confirmed 2× zoom and a coordinate selection. The same timezone lookup as the site now suggests an editable zone offline; its 2019 boundaries are approximate and need user verification. The offline city/coordinate fallback remains available; the public synthetic build does not contain the map. The complete graphic preview and full visual acceptance remain pending.
- Desktop receives five 12-house systems and the actual TT/obliquity inputs from the native provider. It now computes 18 additional 12-house methods through the isolated shared Functions provider adapter and lists the 36 Gauquelin sector boundaries separately. A method unavailable for a given latitude is omitted, never substituted. The provider identity uses an explicit unpinned local-DE441 identifier; synthetic adapter tests pass, but independent numerical and WebView2 acceptance are still pending.
- The isolated Functions worktree includes the four luminary and five planetary kleroi under an explicit VirgoStars legacy profile; its longitude-based day/night classification is a compatibility rule, not an independently established solar altitude. Desktop also exposes essential, Abu Ma'shar and custom Arabic-part modes using a separate Regolo compatibility profile. Formulas requiring the preceding new moon request its longitude from the native provider; a failed search leaves only those formulas unavailable. Regolo's numeric 134° for its labelled 14° Cancer navigation formula is preserved as a compatibility quirk. In a local WebView2 release build the controls were enabled and one essential part produced a position; after the dropdown fix, its selected name remained visible after rendering. Comprehensive independent parity and visual acceptance remain pending.
- A prototype natal planetary hour now uses the native ephemeris rise/set solver and the shared unequal-hour schedule, using the local civil weekday of the sunrise. The displayed glyph is omitted when the three solar events cannot be determined; the solver assumes standard atmospheric conditions at sea level and UT1 approximately UTC. Synthetic contract tests and a real-DE441 smoke test for broad sunrise/sunset ranges in Rome and polar-day unavailability passed. These do not establish numerical precision or visual acceptance of the glyph. The existing MC direction marker is enabled.
- Desktop has an experimental fixed-star ring, native date-dependent position, axis blinking, magnitude scaling and hover details. The owner-supplied extracts produced a private 738-star catalogue with 558 selected conjunction texts; 737 positions are explicitly approximate J2000 directions, and nine incomplete rows were omitted. The local build embeds that catalogue only with an explicit private-build environment switch; a byte-for-byte check confirmed the private catalogue in the executable. A native test using the installed DE441 slice calculated more than 700 of the entries and checked Sirius' broad longitude, but did not independently validate the approximate positions. A local WebView2 release build displayed the 738-star count and approximate-position notice, rendered separated markers, and showed one star's details; its link opened the matching page in the Windows system browser. A limited comparison identified unresolved name/coordinate discrepancies; see [reference comparison](STAR_REFERENCE_COMPARISON.md). A normal public-source build defaults to Sirius only and contains no third-party interpretations. See [the catalogue contract](FIXED_STARS.md). Identity, redistribution, scientific parity and cross-platform link navigation remain unverified.

Local tests, Angular template compilation and the limited WebView2 interactions described above have run. The private-resource local executable is unsigned and unreleased. Complete WebView2 acceptance, scientific parity and release packaging remain unverified. Functions commit `c6ecfde` and Charts commit `85f3250` are now present in the standard sibling checkouts on `codex/desktop-integration-local` branches; main remains unchanged. Desktop's `node_modules` links point directly to those sibling checkouts. An offline `npm ci` from the committed lockfile succeeded in an isolated mirror of the sibling layout. An attempt in the active checkout was blocked by another running Tauri development process holding the CLI binary; missing packages were restored from the verified isolated install without stopping that process, and `npm ls --depth=0` and Desktop tests passed afterward.

The prior Windows Git error was caused by checkout files owned by
Administrators without delete permission for the interactive user. The ACLs
of the exact Git metadata and tracked files needed for these fast-forwards were
repaired after preserving their previous descriptors under ignored `.local/`.
The integration operations now succeed. Wider recursive ACL changes were
rejected by automatic approval review and were not performed, so unrelated
future Git operations may still encounter the same Windows permissions issue.

An optional `scripts/link-local-astrology-libraries.mjs` remains available for
testing other selected worktrees. It is not needed for the standard sibling
checkouts currently in use. The commits are local and have not been merged into
main or released; a new checkout must select the integration branches and build
Charts before installing Desktop dependencies.
