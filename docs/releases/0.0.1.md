# VirgoStars Desktop Lab 0.0.1 — first limited release

**Experimental prototype for Windows 10/11 (x64).** Not production software, not code-signed.

## What it is
A desktop client that draws natal charts, the sky of the moment, transits, synastry and returns **offline**, using the VirgoStars-Ephemeris engine (JPL DE441). Charts are saved in an encrypted local archive. No account, no cloud sync, no network access.

## Limits you should know
- **Dates 1900 to 2033 only.** The last months of 2033 may answer "out of range" (USNO ΔT predictions end in autumn 2033). The 0–5000 range of earlier prototypes is not included; it is planned.
- **Unsigned installer.** Windows SmartScreen will warn ("unknown publisher"). Check the SHA-256 below before running it.
- The engine is experimental and has not had release acceptance testing. Do not rely on it for professional work.
- Bundled data: a 1890–2110 slice of JPL DE441, USNO ΔT tables and the JPL Chiron kernel. Power users can point the app to a full DE441 file with `ephemeris.json` (see `docs/EPHEMERIS_DATA_BUNDLE.md`).
