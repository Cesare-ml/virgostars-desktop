# Security policy

VirgoStars Desktop is an experimental prototype, not a production-ready personal-data application. Do not use it to store real confidential birth records or credentials until its local encryption, authentication and synchronization have been validated.

**Report vulnerabilities privately** using GitHub's repository security advisory feature if enabled, or another private contact method published by the maintainer. Do not include secrets, user data, or exploit details in public GitHub issues. No public security-response SLA is promised at this stage.

See [Security, Privacy and Threat Model](docs/SECURITY_AND_PRIVACY.md) for the current design boundaries. Do not enable privileged WebView/Tauri IPC, network sync or automatic updates without a separate security review.
